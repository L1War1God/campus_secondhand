===============================================
        校园二手交易平台 - 使用说明
===============================================

一、环境要求
------------
- 操作系统:Windows 10/11
- Python 3.8 或更高版本(需已安装)

二、安装步骤
------------
1. 解压此压缩包到任意目录
2. 双击运行 install.bat(仅首次运行需要)
3. 等待依赖安装完成

三、启动程序
------------
双击运行 start.bat
- 程序会自动打开浏览器
- 默认访问地址:http://localhost:5000/page/index

四、测试账号
------------
用户名:testuser
密码:123456

五、功能说明
------------
- 首页:浏览商品、分类筛选、搜索
- 登录/注册:用户认证
- 个人中心:查看订单、购物车、收藏
- 发布商品:发布二手商品

六、项目结构
------------
campus_secondhand/
├── app.py          # Flask主程序
├── config.py       # 配置文件
├── campus_secondhand.db  # SQLite数据库
├── static/         # 静态资源(CSS、JS、图片)
├── templates/      # HTML模板
├── install.bat     # 依赖安装脚本
├── start.bat       # 启动脚本
└── README.txt      # 使用说明
